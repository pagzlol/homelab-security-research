# Ningi Detection Lab Brand Assets

These assets use a clean, professional light style: a navy N mark on white/light-gray backgrounds. The public domain stays `ningi.dev`, but the brand name is `Ningi Detection Lab`.

## Files

- `ningi-brand-mark.svg` - square icon source for favicon, avatar, and profile uses.
- `ningi-wordmark.svg` - horizontal Ningi Detection Lab lockup for headers and docs.
- `ningi-header.svg` - wide website header for `www.ningi.dev`.
- `ningi-social-card.svg` / `ningi-social-card.png` - website Open Graph card, 1200 x 630.
- `github-profile-banner.svg` / `github-profile-banner.png` - GitHub profile or README banner, 1280 x 640.
- `github-social-preview.svg` / `github-social-preview.png` - GitHub repository social preview, 1280 x 640.

## Palette

- Background: `#FFFFFF`, `#F6F7F9`
- Accent bar: `#1F4D8C`
- Navy: `#1F4D8C`, `#16386B`
- Text: `#171A21`, `#565F6D`, `#838C99`

## GitHub

Use `github-profile-banner.png` at the top of profile and project READMEs:

```md
![Ningi Detection Lab](assets/github-profile-banner.png)
```

Use `github-social-preview.png` for the repository social preview image in GitHub repository settings.
